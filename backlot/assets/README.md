# Backlot assets

Drop a real, CC-BY-licensed Blender open-movie `.blend` file here as `movie.blend`.

Recommended: a low/medium-poly sequence from one of the Blender Studio open
movies (e.g. a shot from *Sprite Fox*, *Charge*, or an equivalent short),
downloaded from https://studio.blender.org/films/ — check the specific film's
license page and credit it in the top-level README exactly as required.

Pick a short sequence (a few hundred frames, modest resolution) so a full
render pass costs a few dollars of trial credit and completes in minutes, not
hours. Document the exact film, shot range, and attribution used once chosen.

This directory is gitignored for the `.blend` binary itself (too large for
the repo) — commit only this README and, once selected, the exact download
command + checksum so judges can fetch the identical asset.
